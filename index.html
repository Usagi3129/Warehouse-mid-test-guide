CHAPTER 2-1

การพยากรณ์ความต้องการ (Demand Forecasting & Time Series)

1. ประเภทความต้องการและธรรมชาติการวางแผน
  • Independent Demand (ความต้องการอิสระ): อุปสงค์จากลูกค้าภายนอกโดยตรง เช่น สินค้าสำเร็จรูป ต้องใช้สถิติและข้อมูลในอดีตมาพยากรณ์
  • Dependent Demand (ความต้องการต่อเนื่อง): ชิ้นส่วนหรือวัตถุดิบประกอบ ไม่ต้องพยากรณ์ คำนวณได้แม่นยำจากสูตรโครงสร้างการผลิต (BOM)
2. รูปแบบของข้อมูลความต้องการ (Demand Patterns)
  • Constant (คงที่): ค่าเฉลี่ยสม่ำเสมอ ไม่เปลี่ยนตามเวลา
  • Trend (แนวโน้ม): เพิ่มหรือลดต่อเนื่องในระยะยาว
  • Seasonality (ฤดูกาล): ผันผวนซ้ำๆ ในรอบเวลาแน่นอน (เช่น รายเดือน/รายสัปดาห์)
  • Cyclical (วัฏจักร): ตามภาวะเศรษฐกิจ ระยะเวลานานกว่า 1 ปี
  • Random (ผันแปรสุ่ม): เหตุการณ์ชั่วคราว คาดเดาไม่ได้
3. โมเดล Time Series ยอดนิยม

Naïve:

F(t+1) = D(t)

SMA n งวด:

F(t+1) = ผลรวมยอดจริงย้อนหลัง / n

WMA:

F(t+1) = Σ (น้ำหนัก W × ยอดจริง D)

Single Exponential Smoothing:

F(t+1) = α·D(t) + (1 - α)·F(t)

  • α ต่ำ (ใกล้ 0): เชื่ออดีต เส้นนิ่ง ไม่แกว่งตามเสียงรบกวน
  • α สูง (ใกล้ 1): ตอบสนองต่อยอดจริงล่าสุดอย่างรวดเร็ว

Holt’s Method (Trend):

F(t+m) = S(t) + m·T(t)

Simple Linear Regression (y = a + bx)

1. ตัวแปรและสมการเส้นตรง
y = a + bx
  • x: คาบเวลา (สัปดาห์ที่ 1, 2, 3...)
  • y: ปริมาณขนส่งหรือยอดจริง
  • b (ความชัน): อัตราการเติบโตต่อหน่วยเวลา
  • a (จุดตัดแกน y): ค่าเริ่มต้นทางทฤษฎี
2. สูตรคำนวณในห้องสอบ
b = [ n·Σxy - (Σx)(Σy) ] / [ n·Σx² - (Σx)² ]
a = ȳ - b·x̄    (x̄ = Σx / n , ȳ = Σy / n)
⚠️ ทริคห้องสอบข้อสังเกต:
  • ถ้า n = 5 ตัวส่วนของ b จะเท่ากับ 5(55) - (15)² = 50 เสมอ
  • ถามเส้นทางเติบโตสูงสุด → เลือกเส้นทางที่มี ค่า b มากที่สุด
  • พยากรณ์สัปดาห์ถัดไป → แทนค่า x ตามลำดับถัดไป

Basic EOQ, Backorders & POQ Model

1. Basic EOQ Model (ของไม่ขาดมือ)
EOQ (Q*) = √(2DS / H)    (H = h × C)
  • ต้นทุนรวม: TC = (D/Q)·S + (Q/2)·H
  • กฎเหล็ก: ณ จุด EOQ ต้นทุนสั่งซื้อจะเท่ากับต้นทุนถือครองพอดี
2. EOQ with Planned Backorders (ยอมให้ขาดมือ)
Q* = √( [2DS/H] × [(H+P)/P] )
ขาดมือสูงสุด (B*) = Q* × [ H / (H + P) ]
3. POQ / EPQ Model (ทยอยผลิต ทยอยใช้)
  • เงื่อนไขบังคับ: อัตราผลิต p > u (หรือ d) เสมอ
  • Qp* = √(2DS / H) × √(p / (p - u))
  • สต็อกสูงสุด (Imax): Qp* × [ (p - u) / p ]

CHAPTER 3-2 & 3-3

Quantity Discount, ROP & Safety Stock

1. Quantity Discount (ส่วนลดตามปริมาณ)
  1. คำนวณ EOQ แต่ละช่วงราคา (ระวัง H เปลี่ยนตามราคา C)
  2. ตรวจสอบช่วง: หาก EOQ ต่ำกว่าขั้นต่ำ → ปัดขึ้นเป็นขอบล่างของช่วงทันที
  3. คำนวณ TC รวมค่าซื้อ: TC = (D/Q)·S + (Q/2)·H + D·C แล้วเลือกค่าต่ำที่สุด
2. ROP และ Safety Stock (SS)
ROP = (d̄ × LT̄) + SS
กรณีความผันผวน สูตร Safety Stock (SS)
1. แน่นอนทั้งคู่SS = 0
2. Demand ผันผวน, LT แน่นอนSS = Z · σd · √LT
3. Demand แน่นอน, LT ผันผวนSS = Z · d̄ · σLT
4. ผันผวนทั้งคู่ (ออกบ่อยสุด)SS = Z · √(LT̄·σd² + d̄²·σLT²)

ค่า Z ตาม Service Level: 90% (1.28), 95% (1.65), 99% (2.33)
