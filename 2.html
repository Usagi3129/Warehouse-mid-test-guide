CHAPTER 2-1

Demand Forecasting: พื้นฐาน & Time Series

1. ประเภทความต้องการ (Types of Demand)
  • Independent Demand: สินค้าสำเร็จรูป ลูกค้าภายนอก → ต้องใช้สถิติพยากรณ์
  • Dependent Demand: ชิ้นส่วน/วัตถุดิบ → คำนวณจาก BOM ไม่ต้องพยากรณ์
2. รูปแบบความต้องการ (Demand Patterns)
  • Constant: นิ่ง เสถียร ไม่เปลี่ยนตามเวลา
  • Trend: เพิ่มหรือลดลงต่อเนื่องตามเวลา
  • Seasonality: รอบเวลาแน่นอน คาดเดาได้ (สัปดาห์/ปี)
  • Cyclical: รอบวัฏจักรเศรษฐกิจ (> 1 ปี)
  • Random: ผันแปรสุ่ม ชั่วคราว คาดเดาไม่ได้
3. โมเดล Time Series ยอดนิยม
  • Naïve: F(t+1) = D(t)
  • SMA n งวด: F(t+1) = ผลรวม D ย้อนหลัง / n
  • WMA: F(t+1) = Σ (น้ำหนัก Wi × ยอดจริง Di)
  • Single Exponential Smoothing:
    F(t+1) = α·D(t) + (1 - α)·F(t)
    • α ต่ำ (ใกล้ 0) → เชื่อข้อมูลเก่า นิ่ง ไม่แกว่ง
    • α สูง (ใกล้ 1) → ตอบสนองเร็ว ไวต่อข้อมูลล่าสุด
  • Holt’s Method (Trend): F(t+m) = S(t) + m·T(t)

Simple Linear Regression (y = a + bx)

1. ตัวแปรสมการเส้นตรง
y = a + bx
  • x: คาบเวลา (สัปดาห์ที่ 1, 2, 3...)
  • y: ปริมาณขนส่งจริง (ตัน)
  • b: ความชัน = อัตราการเติบโตต่อสัปดาห์
  • a: จุดตัดแกน y (ค่าเริ่มต้น)
2. สูตรคำนวณเข้าห้องสอบ
  • b = [ n·Σxy - (Σx)(Σy) ] / [ n·Σx² - (Σx)² ]
  • a = ȳ - b·x̄
  • x̄ = Σx / n , ȳ = Σy / n
⚠️ ทริคห้องสอบข้อ 1
  • เมื่อ n = 5 ตัวส่วนของ b คือ 5(55) - (15)² = 50 เท่ากันทุกเส้นทาง
  • ถ้าถาม "เส้นทางใดเติบโตสูงที่สุด" → เลือกเส้นทางที่มี ค่า b (ความชัน) มากที่สุด
  • พยากรณ์สัปดาห์ที่ 6 → แทนค่า x = 6 ลงในสมการ

CHAPTER 3-1 & 3-2

Basic EOQ & ยอมให้ของขาดมือ (Backorders)

1. Basic EOQ Model (ของไม่ขาดมือ)
  • ปริมาณสั่งซื้อประหยัดสุด:
    EOQ = √( 2DS / H )   (H = h × C)
  • ต้นทุนรวมต่อปี: TC = (D/Q)·S + (Q/2)·H
  • จำนวนครั้งสั่ง/ปี: N = D / Q
  • ระยะเวลารอบสั่ง: T = (Q / D) × วันทำงาน
  • * ณ จุด EOQ ต้นทุนสั่งซื้อจะเท่ากับต้นทุนถือครองพอดี
2. EOQ with Backorders (ยอมให้ของขาดมือ)
  • P: ต้นทุนของขาดมือ (บาท/หน่วย/ปี)
  • ปริมาณสั่งซื้อ:
    Q* = √( [2DS/H] × [(H+P)/P] )
  • ขาดมือสูงสุด: B* = Q* × [ H / (H + P) ]
  • สต็อกสูงสุด: Smax = Q* - B*
  • ต้นทุนรวม:
    TC = (D/Q*)S + [Smax²/(2Q*)]H + [B*²/(2Q*)]P

CHAPTER 3-2

POQ Model (ผลิตไปใช้ไป) & Quantity Discount

1. POQ / EPQ Model (ทยอยผลิต ทยอยใช้)
  • เงื่อนไข: p (อัตราผลิต) > d (อัตราใช้) เสมอ
  • ปริมาณผลิตเหมาะสม:
    Qp* = √( 2DS / H ) × √( p / (p - d) )
  • สินค้าคงคลังสูงสุด: Imax = Qp* × [ (p - d) / p ]
  • ต้นทุนรวมต่อปี: TC = (D/Qp*)·S + (Imax/2)·H
  • * ระวังหน่วย: D ต้องเป็นต่อปี, ส่วน p และ d ต้องเป็นต่อวัน
2. Quantity Discount (ส่วนลดปริมาณ)
  1. คำนวณ EOQ แต่ละช่วงราคา: EOQ = √( 2DS / H )
  2. ตรวจช่วงสั่งซื้อจริง:
    • ถ้าอยู่ในช่วง → ใช้เลขนั้น
    • ถ้าต่ำกว่าขั้นต่ำ → ปัดขึ้นเป็นขอบล่างของช่วงทันที
  3. คำนวณ TC รวมค่าซื้อสินค้า:
    TC = (D/Q)·S + (Q/2)·H + D·C
  4. เลือกสั่งซื้อที่ให้ TC ต่ำที่สุด

CHAPTER 3-3

จุดสั่งซื้อใหม่ (ROP) & สต๊อกปลอดภัย (Safety Stock)

สูตรหลัก: ROP = (d̄ × LT̄) + SS
กรณี สถานการณ์ สูตร Safety Stock (SS)
1 Demand แน่นอน, LT แน่นอน SS = 0
2 Demand ผันผวน, LT แน่นอน SS = Z · σd · √LT
3 Demand แน่นอน, LT ผันผวน SS = Z · d̄ · σLT
4 ผันผวนทั้งคู่ (ออกสอบบ่อย) SS = Z · √( LT̄·σd² + d̄²·σLT² )
ค่า Z ตาม Service Level
  • 90% → Z = 1.28
  • 95% → Z = 1.65 (ใช้บ่อยสุด)
  • 97.5% → Z = 1.96
  • 99% → Z = 2.33
สูตรสถิติจากตารางความถี่
  • เฉลี่ยถ่วงน้ำหนัก: X̄ = Σ(fi·Xi) / Σfi
  • ส่วนเบี่ยงเบน:
    σ = √[ Σ fi(Xi - X̄)² / (n - 1) ]

PRACTICE QUIZ

แบบทดสอบวัดความเข้าใจ 10 ข้อ (คลิกเลือกคำตอบเพื่อดูเฉลย)

1. คุณลักษณะสำคัญที่สุดของเทคนิคการพยากรณ์เชิงคุณภาพแบบ Delphi Method คือข้อใด
ก. รวมตัวแทนฝ่ายขายมาประชุมถกเถียงกันในห้องประชุมใหญ่
ข. ผู้เชี่ยวชาญตอบแบบสอบถามหลายรอบโดยไม่เปิดเผยตัวตนต่อกัน เพื่อลดอิทธิพลทางสังคม
ค. สอบถามความพึงพอใจจากกลุ่มผู้บริโภคโดยตรงผ่านการสุ่มตัวอย่าง
ง. อาศัยการตัดสินใจเด็ดขาดของผู้บริหารระดับสูงเพียงคนเดียว
เฉลย ข: Delphi Method เน้นระดมความคิดเห็นจากผู้เชี่ยวชาญหลายรอบโดยไม่เปิดเผยตัวตน (Anonymous) เพื่อป้องกันไม่ให้ผู้มีอิทธิพลหรือเสียงดังชี้นำความคิดเห็นคนอื่น
2. หากข้อมูลยอดขายจริงมีความผันผวนสูงมากจากปัจจัยภายนอกแบบสุ่ม (Random variation) ผู้พยากรณ์ควรเลือกค่า α ใน Exponential Smoothing อย่างไร
ก. กำหนดให้ α มีค่าใกล้ 1.0
ข. กำหนดให้ α มีค่าใกล้ 0 (เช่น 0.1 – 0.2) เพื่อกรองสัญญาณรบกวน
ค. กำหนดให้ α = 0.5 เสมอ
ง. ค่า α ไม่มีผลต่อความแกว่งของเส้นพยากรณ์
เฉลย ข: ค่า α ต่ำ (ใกล้ 0) จะให้น้ำหนักกับค่าพยากรณ์ในอดีตมากกว่ายอดจริงล่าสุด ทำให้เส้นพยากรณ์มีความราบเรียบ (Smooth) และไม่แกว่งตามความผันแปรสุ่ม
3. ในการสร้างสมการเส้นตรง y = a + bx หากพบว่า เส้นทางที่ 1 มี b = 4.5, เส้นทางที่ 2 มี b = 8.2, เส้นทางที่ 3 มี b = 2.1 ข้อใดสรุปได้ถูกต้องที่สุด
ก. เส้นทางที่ 1 มียอดขนส่งรวมในอดีตสูงที่สุด
ข. เส้นทางที่ 3 มีความแม่นยำในการพยากรณ์สูงที่สุด
ค. เส้นทางที่ 2 มีอัตราการเติบโตของปริมาณขนส่งต่อสัปดาห์สูงที่สุด
ง. เส้นทางที่ 2 เริ่มต้นด้วยปริมาณขนส่งสูงกว่าเส้นทางอื่นเสมอ
เฉลย ค: ค่า b คือความชัน (Slope) ซึ่งแสดงอัตราการเปลี่ยนแปลงหรืออัตราการเติบโตต่อหนึ่งหน่วยเวลา เส้นทางที่มีค่า b สูงที่สุด (8.2) ย่อมเติบโตเร็วที่สุด
4. ณ จุดสั่งซื้อที่ประหยัดที่สุด (Basic EOQ) ต้นทุนการสั่งซื้อรวมต่อปี และต้นทุนการถือครองรวมต่อปี มีความสัมพันธ์กันอย่างไร
ก. ต้นทุนการสั่งซื้อสูงกว่าต้นทุนการถือครองเป็นสองเท่า
ข. ต้นทุนการถือครองสูงกว่าต้นทุนการสั่งซื้อเสมอ
ค. ทั้งสองต้นทุนมีมูลค่าเท่ากันพอดี และทำให้ต้นทุนรวมต่ำที่สุด
ง. ทั้งสองต้นทุนลดลงจนเป็นศูนย์พร้อมกัน
เฉลย ค: กราฟ EOQ เป็นจุดตัดระหว่างเส้นต้นทุนสั่งซื้อที่ลาดลงกับเส้นต้นทุนถือครองที่ชันขึ้น ณ จุดตัดนี้ ต้นทุนทั้งสองจะเท่ากันพอดี และส่งผลให้เส้นต้นทุนรวม (Total Cost) อยู่ ณ จุดต่ำสุด
5. หากบริษัทเปลี่ยนนโยบายจากการสั่งซื้อบ่อยๆ ครั้งละน้อยๆ มาเป็นการสั่งล็อตใหญ่ นานๆ สั่งที จะเกิดผลกระทบอย่างไรต่อต้นทุน
ก. ต้นทุนการสั่งซื้อต่อปีเพิ่มขึ้น, ต้นทุนการถือครองต่อปีลดลง
ข. ต้นทุนการสั่งซื้อต่อปีลดลง, ต้นทุนการถือครองต่อปีเพิ่มขึ้น
ค. ทั้งสองต้นทุนลดลงพร้อมกัน
ง. ต้นทุนรวมลดลงโดยที่ต้นทุนรายย่อยไม่เปลี่ยนแปลง
เฉลย ข: สั่งล็อตใหญ่ (Q มาก) ทำให้จำนวนครั้งที่สั่งต่อปี (D/Q) ลดลง ส่งผลให้ค่าสั่งซื้อรวมลดลง แต่ปริมาณสต็อกเฉลี่ยในคลัง (Q/2) สูงขึ้น จึงต้องจ่ายค่าเก็บรักษาเพิ่มขึ้น
6. ข้อใดเป็นข้อแตกต่างสำคัญระหว่าง Backorders (การค้างส่ง) และ Lost Sales (การสูญเสียยอดขาย)
ก. Backorders ลูกค้ายกเลิกทันที แต่ Lost Sales ยินดีรอรับสินค้า
ข. Backorders เกิดกับสินค้าสั่งผลิต ส่วน Lost Sales เกิดเฉพาะโรงพยาบาล
ค. Backorders ลูกค้ายินดีรอรับของเมื่อสินค้ามาถึง ส่วน Lost Sales คือยอดขายสูญหายไปถาวร
ง. Backorders ไม่มีต้นทุนความเสียหายใดๆ เกิดขึ้น
เฉลย ค: Backorder หมายถึงยอมให้สินค้าขาดมือชั่วคราวโดยลูกค้าไม่ยกเลิกออเดอร์ เมื่อสินค้าเข้าคลังจะส่งมอบย้อนหลังได้ทั้งหมด แต่ Lost Sales คือลูกค้าไปซื้อที่อื่นทันที ทำให้เสียยอดขายนั้นไปถาวร
7. ในแบบจำลอง POQ/EPQ ข้อใดเป็นเงื่อนไขบังคับ (Constraint) ที่ต้องเป็นจริงเสมอเพื่อให้แบบจำลองทำงานได้
ก. อัตราการผลิต (p) ต้องเท่ากับอัตราการใช้ (u)
ข. อัตราการใช้ (u) ต้องมากกว่าอัตราการผลิต (p)
ค. อัตราการผลิต (p) ต้องมากกว่าอัตราการใช้ (u) เสมอ
ง. โรงงานต้องเปิดทำงาน 365 วันต่อปี
เฉลย ค: ในสูตร POQ มีพจน์ √(p / (p - u)) หาก p ≤ u ตัวส่วนจะติดลบหรือเป็นศูนย์ ซึ่งในความเป็นจริงหากผลิตช้ากว่าที่ใช้ สต็อกจะไม่สามารถสะสมเป็น I_max ได้ และจะขาดสต็อกทันที
8. ในแบบจำลอง Quantity Discount หากคำนวณ EOQ แล้วได้ค่าน้อยกว่าขั้นต่ำของช่วงราคานั้น ต้องดำเนินการอย่างไรต่อ
ก. ตัดระดับราคานั้นทิ้งทันที
ข. ปรับปริมาณสั่งซื้อขึ้นไปที่จุดต่ำสุด (ขอบล่าง) ของช่วงราคานั้น แล้วนำไปคำนวณ TC รวม
ค. ใช้ค่า EOQ เดิมที่ได้คำนวณไว้
ง. นำค่าเฉลี่ยของช่วงราคานั้นมาใช้แทน
เฉลย ข: หาก EOQ คำนวณได้ต่ำกว่าขั้นต่ำ แสดงว่าสั่งที่จุด EOQ ไม่ได้ส่วนลด จึงต้องปรับปริมาณสั่งซื้อขึ้นไปที่ "ขอบล่างของช่วง (Lower boundary)" เพื่อให้ได้รับสิทธิ์ส่วนลด แล้วนำค่า Q นั้นไปเปรียบเทียบ TC รวม
9. หากอุปสงค์ของลูกค้า (Demand) และเวลานำ (Lead Time) มีค่าแน่นอนและคงที่ทั้งคู่ ปริมาณ Safety Stock (SS) ควรมีค่าเท่าใด
ก. SS = 0 เนื่องจากไม่มีความเสี่ยงด้านความผันผวน
ข. ต้องมีค่าเท่ากับยอดขายเฉลี่ย 1 สัปดาห์เสมอ
ค. SS = Z · σd · √LT
ง. ต้องมีค่าเท่ากับขนาด EOQ
เฉลย ก: Safety Stock มีไว้เพื่อรับมือกับ "ความไม่แน่นอน" เมื่อทั้งความต้องการและเวลานำทราบค่าแน่นอน 100% จึงไม่จำเป็นต้องสำรองของเผื่อไว้ (SS = 0) และ ROP = d̄ × LT ได้เลย
10. เพราะเหตุใดแบบจำลอง Fixed-Order-Interval (FOI) จึงมักต้องถือ Safety Stock สูงกว่าระบบ Reorder Point (ROP)
ก. เพราะระบบ FOI มักใช้กับสินค้าที่มีมูลค่าสูงกว่า
ข. เพราะระบบ FOI ต้องรับความเสี่ยงครอบคลุมทั้งช่วงทบทวนและเวลานำ (OI + LT)
ค. เพราะระบบ FOI ตรวจนับสต็อกแบบต่อเนื่องทุกวัน
ง. เพราะซัพพลายเออร์ในระบบ FOI ส่งมอบสินค้าล่าช้ากว่าเสมอ
เฉลย ข: ระบบ ROP เผชิญความเสี่ยงเฉพาะช่วงรอของ (LT) แต่ระบบ FOI ตรวจนับเป็นงวด (OI) ความเสี่ยงจึงลากยาวตลอดช่วง (OI + LT) สูตร Safety Stock จึงคูณด้วย √(OI + LT) ส่งผลให้ต้องถือสต็อกสำรองมากกว่า
