CHAPTER 2-1

Demand Forecasting: พื้นฐาน & อนุกรมเวลา (Time Series)

1. ประเภทความต้องการ (Types of Demand)
  • Independent: สินค้าสำเร็จรูป เกิดจากลูกค้าภายนอก → ต้องพยากรณ์
  • Dependent: วัตถุดิบ/ชิ้นส่วน → คำนวณจาก BOM ไม่ต้องพยากรณ์
2. รูปแบบความต้องการ (Demand Patterns)
  • Constant: นิ่ง เสถียร ไม่เปลี่ยนตามเวลา
  • Trend: เพิ่มหรือลดลงต่อเนื่อง
  • Seasonality: รอบเวลาแน่นอน คาดเดาได้
  • Cyclical: รอบวัฏจักรเศรษฐกิจ (> 1 ปี)
  • Random: ผันแปรสุ่ม ชั่วคราว คาดเดาไม่ได้
3. สูตรคำนวณ Time Series
  • Naïve: F(t+1) = D(t)
  • SMA n งวด: F(t+1) = ผลรวม D / n
  • WMA: F(t+1) = Σ (Wi × Di) (ΣW = 1)
  • Exponential Smoothing:
    F(t+1) = α·D(t) + (1 - α)·F(t)
    • α ต่ำ (ใกล้ 0) → เชื่อข้อมูลเก่า นิ่ง ไม่แกว่ง
    • α สูง (ใกล้ 1) → ไวต่อข้อมูลล่าสุด ตอบสนองเร็ว
  • Holt’s Method: F(t+m) = S(t) + m·T(t)

CHAPTER 2-2

Simple Linear Regression (y = a + bx)

1. ตัวแปรสมการเส้นตรง
  • x: คาบเวลา (สัปดาห์ที่ 1, 2, 3...)
  • y: ปริมาณขนส่งจริง (ตัน)
  • b: ความชัน = อัตราการเติบโตต่อสัปดาห์
  • a: จุดตัดแกน y (ค่าเริ่มต้น)
2. สูตรคำนวณ
  • b = [ n·Σxy - (Σx)(Σy) ] / [ n·Σx² - (Σx)² ]
  • a = ȳ - b·x̄
  • x̄ = Σx / n , ȳ = Σy / n
⚠️ ทริคห้องสอบ (ข้อ 1)
  • เมื่อ n = 5 ตัวส่วนของสูตร b จะเท่ากับ 5(55) - (15)² = 50 เสมอ
  • ถ้าถามหา "เส้นทางที่เติบโตสูงที่สุด" → เลือกเส้นทางที่มี ค่า b สูงสุด
  • พยากรณ์สัปดาห์ที่ 6 → แทน x = 6 ลงในสมการ

CHAPTER 3-1 & 3-2

Basic EOQ & แบบจำลองยอมให้ของขาดมือ (Backorders)

1. Basic EOQ (ของไม่ขาดมือ)
  • ปริมาณสั่งซื้อ: EOQ = √( 2DS / H )   (H = h × C)
  • ต้นทุนรวม: TC = (D/Q)·S + (Q/2)·H
  • จำนวนครั้งสั่ง/ปี = D / Q
  • ระยะเวลารอบสั่ง = (Q / D) × วันทำงานต่อปี
  • * ณ จุด EOQ: ต้นทุนสั่งซื้อ = ต้นทุนถือครองพอดี
2. EOQ with Backorders
  • P: ต้นทุนของขาดมือ (บาท/หน่วย/ปี)
  • ปริมาณสั่งซื้อ:
    Q* = √( [2DS/H] × [(H+P)/P] )
  • ขาดมือสูงสุด: B* = Q* × [ H / (H + P) ]
  • สต็อกสูงสุด: Smax = Q* - B*
  • ต้นทุนรวม:
    TC = (D/Q*)S + [Smax²/(2Q*)]H + [B*²/(2Q*)]P

CHAPTER 3-2

POQ Model (ผลิตไปใช้ไป) & Quantity Discount

1. POQ / EPQ (ทยอยผลิต ทยอยใช้)
  • เงื่อนไข: p (อัตราผลิต) > d (อัตราใช้)
  • ปริมาณผลิต:
    Qp* = √( 2DS / H ) × √( p / (p - d) )
  • สต็อกสูงสุด: Imax = Qp* × [ (p - d) / p ]
  • ต้นทุนรวม: TC = (D/Qp*)·S + (Imax/2)·H
  • * ระวัง: D ต้องเป็นต่อปี (เดือน × 12) ส่วน p และ d ต้องเป็นต่อวัน
2. Quantity Discount (ส่วนลดปริมาณ)
  1. คำนวณ EOQ แต่ละช่วงราคา: EOQ = √( 2DS / H )
  2. ตรวจช่วงสั่งซื้อ:
    • ถ้าอยู่ในช่วง → ใช้เลขนั้น
    • ถ้าต่ำกว่าขั้นต่ำ → ปัดขึ้นเป็นขอบล่างของช่วงทันที
  3. คิดต้นทุนรวม: TC = (D/Q)S + (Q/2)H + DC
  4. เลือกสั่งซื้อที่ให้ TC ต่ำที่สุด

CHAPTER 3-3

จุดสั่งซื้อใหม่ (ROP) & สต๊อกปลอดภัย (Safety Stock)

สูตรหลัก: ROP = (d̄ × LT̄) + SS
กรณี สถานะ Demand & Lead Time สูตร Safety Stock (SS)
1 Demand แน่นอน, LT แน่นอน SS = 0
2 Demand ผันผวน, LT แน่นอน SS = Z · σd · √LT
3 Demand แน่นอน, LT ผันผวน SS = Z · d̄ · σLT
4 ผันผวนทั้งคู่ (ออกสอบบ่อย) SS = Z · √( LT̄·σd² + d̄²·σLT² )
ค่า Z ตาม Service Level
  • 90% → Z = 1.28
  • 95% → Z = 1.65 (ใช้บ่อยสุด)
  • 97.5% → Z = 1.96
  • 99% → Z = 2.33
สูตรสถิติจากตารางความถี่
  • เฉลี่ยถ่วงน้ำหนัก: X̄ = Σ(fi·Xi) / Σfi
  • ส่วนเบี่ยงเบนมาตรฐาน:
    σ = √[ Σ fi(Xi - X̄)² / (n - 1) ]
