EXAM REVIEW GUIDE

สรุปประเด็นทบทวนหน้าห้องสอบ (ตรงตามสไลด์อาจารย์)

1. จุดประสงค์หลักของการจัดการคลังสินค้า
  • ลดต้นทุนรวม: ควบคุมต้นทุนการถือครอง สั่งซื้อ และความเสียหาย
  • รักษาระดับการบริการ: มีสินค้าพร้อมส่งมอบ ตรงเวลา
  • รองรับความไม่แน่นอน: เป็นกันชนรับมือความผันผวนของ Demand และ Lead Time
  • ประหยัดจากขนาด: สั่งหรือผลิตล็อตใหญ่เพื่อรับส่วนลดและลดค่าขนส่ง
2. Demand Forecasting มีกี่แบบ?
  • Qualitative (เชิงคุณภาพ): ใช้ความคิดเห็นผู้เชี่ยวชาญ เหมาะกับสินค้าใหม่
  • Time Series (อนุกรมเวลา): ใช้ประวัติยอดขาย เหมาะกับสินค้ามีข้อมูลเดิม
  • Causal (เชิงเหตุผล): ใช้สมการเส้นตรง ($y = a + bx$) หาความสัมพันธ์
3. สูตรการหาค่าความคลาดเคลื่อน
  • MAD:
    MAD = Σ |Dt - Ft| / n
  • MSE:
    MSE = Σ (Dt - Ft)² / n
  • MAPE:
    MAPE = [ Σ (|Dt - Ft| / Dt) / n ] × 100%
4. EOQ และ ROP / SS
  • EOQ Models: Basic, Backorders, POQ, Quantity Discount
  • ROP & SS 4 กรณี: ตั้งแต่ SS = 0 ไปจนถึงกรณีผันผวนทั้งคู่
    SS = Z · √(LT̄·σd² + d̄²·σLT²)
